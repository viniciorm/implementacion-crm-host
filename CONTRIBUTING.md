# Reglas para documentar

- Describir el problema, la evidencia, la solución y el resultado sin identificar a clientes ni personas.
- No incluir nombres de empresas, correos, dominios, enlaces a sistemas, identificadores de planillas, rutas reales, direcciones IP, claves ni capturas con información identificable.
- No copiar código ni recursos gráficos de un cliente. Usar ejemplos genéricos y datos ficticios explícitos.
- Diferenciar un hecho observado de un riesgo o hipótesis; no presentar una solución prevista como si estuviera probada.
- Revisar archivos y diferencias antes de cada publicación. Una vez incorporado un secreto al historial, eliminarlo de un archivo posterior no garantiza su eliminación: corresponde revocar la credencial y tratar el incidente.
